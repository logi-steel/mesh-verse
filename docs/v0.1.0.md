# v0.1.0: First Relay

This is the first experimental Mesh Verse release.

It relays public text between one selected Meshtastic channel and one selected MeshCore channel using two USB-connected radios and a host computer.

Included: public relay, aliases, visible `[MV/...]` markers, local echo protection, `--check-config`, `--dry-run`, automated tests, and a systemd template.

This release does not relay private messages, files, telemetry, positions, or raw packets. Test with `--dry-run` before real transmissions.
